# Майстерня з ремонту сумок — сайт

Одно­сторінковий сайт майстерні (Дніпро, просп. Дмитра Яворницького, 115): ремонт сумок, валіз, рюкзаків і парасольок, пошиття ручок, ключі (в тому числі електронні), люверси, кнопки та заклепки.

Мови: українська (за замовчуванням, `/`) і російська (`/ru/`). Перемикач «UA | RU» є в шапці кожної сторінки. Без фреймворків і скриптів: кожна сторінка — один HTML-файл з вбудованими стилями, тому вона швидко завантажується.

## Файли

- `index.html` — українська версія (стилі, SEO-мета-теги, Schema.org JSON-LD)
- `ru/index.html` — російська версія (той самий дизайн і структура)
- `favicon.svg`, `apple-touch-icon.png` — іконки
- `og-image.svg` / `og-image.png` та `og-image-ru.svg` / `og-image-ru.png` — картинки для превʼю в соцмережах (PNG генеруються з SVG)
- `robots.txt`, `sitemap.xml` — для пошукових систем (у sitemap обидві мовні версії звʼязані через hreflang)

## Що ще зробити для пошуку

1. Додати сайт у [Google Search Console](https://search.google.com/search-console) і надіслати `sitemap.xml`.
2. Створити профіль у Google Business Profile (картка на Google Картах) з тією ж адресою, телефонами та графіком.
3. Вказати адресу сайту в соцмережах і на картках каталогів, якщо вони є.
